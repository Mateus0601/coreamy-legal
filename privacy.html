Política de Privacidade

Última atualização: 5 de março de 2026

1. Introdução

Esta Política de Privacidade descreve como o aplicativo Coreamy Auto-Poster ("Aplicativo") coleta, usa e protege informações quando você utiliza nosso serviço.

2. Dados Coletados

O Aplicativo coleta e armazena localmente apenas os dados estritamente necessários para seu funcionamento:

  • Tokens de autenticação TikTok: access token e refresh token, armazenados localmente no arquivo .tokens.json no dispositivo do usuário.
  • Histórico de publicações: registro de vídeos já publicados, armazenado localmente no arquivo .post-history.json.
  • Logs de operação: registros técnicos de execução, armazenados localmente na pasta logs/.

3. Dados NÃO Coletados

O Aplicativo não coleta:

  • Informações pessoais identificáveis (nome, email, telefone)
  • Dados de navegação ou cookies
  • Informações de localização
  • Dados de terceiros ou de seguidores
  • Métricas ou analytics de vídeos publicados

4. Armazenamento de Dados

Todos os dados são armazenados exclusivamente no dispositivo local do usuário. Nenhum dado é transmitido para servidores externos, exceto as chamadas necessárias à API do TikTok para autenticação e publicação de vídeos.

5. Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Autenticar com a API do TikTok
  • Publicar vídeos na conta TikTok do usuário
  • Evitar publicações duplicadas
  • Registrar logs para diagnóstico de problemas

6. Compartilhamento de Dados

Não compartilhamos dados com terceiros. As únicas comunicações externas são com a API oficial do TikTok, conforme necessário para o funcionamento do Aplicativo.

7. Segurança

Os tokens de autenticação são armazenados em arquivos protegidos pelo sistema operacional do usuário. Recomendamos não compartilhar os arquivos .env e .tokens.json.

8. Exclusão de Dados

O usuário pode excluir todos os dados a qualquer momento removendo os arquivos .tokens.json, .post-history.json e a pasta logs/. A desinstalação do Aplicativo remove automaticamente todos os dados.

9. Direitos do Usuário

Em conformidade com a Lei Geral de Proteção de Dados (LGPD), o usuário tem direito a acessar, corrigir e excluir seus dados a qualquer momento. Como todos os dados são locais, o usuário tem controle total.

10. Alterações

Esta política pode ser atualizada a qualquer momento. Recomendamos revisá-la periodicamente.

11. Contato

Para dúvidas sobre esta política, entre em contato pelo repositório do projeto.
